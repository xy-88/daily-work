# 账簿 · 记账软件 PRD

## 1. 产品概述

一款面向个人用户的"编辑式账簿"记账软件，支持自动识别微信/支付宝账单（CSV 与粘贴文本），按类目智能归类，并提供多维度统计与多端数据同步查看能力。

- 解决问题：手动逐笔记账负担重、账单分散在多个支付平台、缺乏统一可读的财务视图。
- 目标用户：注重财务秩序感的城市白领、自由职业者、有记账习惯但嫌传统 App 啰嗦的人。
- 产品价值：把"记账"从繁琐操作变成一份每月可阅读、可归档的"个人财务季刊"。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 本地用户 | 无需注册（本地账号） | 全部功能：导入、统计、分类管理、导出、同步令牌 |

### 2.2 功能模块

1. **概览页 (Ledger)**：当月收支总览、净值卡片、近期流水、月度趋势迷你图。
2. **流水页 (Entries)**：完整交易列表，支持搜索、筛选（类目/平台/收支类型）、分组与编辑。
3. **导入页 (Import)**：微信/支付宝账单自动识别（CSV 上传 + 文本粘贴），预解析、智能归类、批量入库。
4. **统计页 (Analytics)**：类目占比环形图、收支趋势折线、Top 商户、月度对比柱状图。
5. **设置页 (Settings)**：类目管理、同步令牌、数据导出/导入、外观偏好。

## 3. 核心流程

### 3.1 账单自动识别流程

用户在导入页粘贴微信/支付宝账单文本或上传 CSV → 系统按平台格式正则解析每行（日期、交易类型、对方、商品、金额、收/支、支付方式）→ 对每条记录基于"商户关键词→类目"规则库自动归类 → 预览表格中高亮关键字段并允许逐条修正 → 确认后批量写入本地数据库 → 概览/流水/统计即时更新。

### 3.2 多端同步流程

设备 A 在设置页生成同步令牌（含加密密钥）→ 设备 B 输入令牌建立配对 → 任一端写入数据时打包为变更集，通过同步令牌编码为可分享的同步串码（导出/扫码）→ 对端导入同步串码后按时间戳合并（last-write-wins）→ 双端数据一致。

```mermaid
flowchart LR
    A["微信/支付宝账单"] --> B["粘贴或上传"]
    B --> C["正则解析"]
    C --> D["关键词智能归类"]
    D --> E["预览与人工修正"]
    E --> F["写入 IndexedDB"]
    F --> G["概览/流水/统计更新"]
    F --> H["生成同步串码"]
    H --> I["对端导入合并"]
```

## 4. 用户界面设计

### 4.1 设计风格 —— "编辑式账簿 (Editorial Ledger)"

把记账软件做成一份纸质精装账簿与私人银行年度报告的混合体，强调秩序、克制与可读性，拒绝通用金融蓝渐变。

- **主色**：暖纸奶油 `#F4EFE6` 背景；墨黑 `#1C1917` 正文。
- **强调色**：支出用牛血红 `#9B2C2C`，收入用森绿 `#2F5D3A`，品牌点缀用暖金 `#B8893E`。
- **按钮**：直角或极小圆角（2px），墨黑实色填充配奶油文字；次级按钮为描边。
- **字体**：标题用 Fraunces（可变衬线，带光学斜体）；正文/UI 用 Hanken Grotesk；所有数字用 JetBrains Mono 等宽对齐。
- **布局**：左固定窄边栏导航 + 主内容区；主内容区采用 12 列网格，卡片可破格重叠、错位留白。
- **图标/装饰**：细线 SVG 图标 + 衬线序号 + 章节式分隔线（如 "§ Ⅱ"），账簿页码感。

### 4.2 页面设计概览

| 页面 | 模块 | UI 元素 |
|------|------|--------|
| 概览页 | 净值卡片 | 墨黑大数字 + 牛血红/森绿涨跌指示 + 细衬线标签 |
| 概览页 | 月度趋势 | 极简柱状图，支出红柱向下、收入绿柱向上 |
| 概览页 | 月历热力 | 7×5 网格，色块深浅表示当日支出强度 |
| 流水页 | 流水条目 | 左侧类目色条 + 商户名 + 日期小字 + 右侧等宽数字金额 |
| 导入页 | 预览表格 | 高亮金额（金色下划线）、日期（衬线）、自动归类标签 |
| 统计页 | 环形图 | 牛血红/森绿双色环，中心显示总额 |
| 设置页 | 类目卡片 | 色点 + 类目名 + 关键词标签 + 编辑控件 |

### 4.3 响应式

桌面优先（≥1024px 完整双栏布局），平板自适应为单栏卡片，移动端折叠为底部 Tab 导航 + 单列流；所有数字与表格在窄屏保持等宽对齐。
